# Blueprint Grid

Genre: Technical
Macrostructure: Mosaic
Density: Compact
Shape: Sharp
Motion: None
Typography: Monospace
Color: Duotone

## Rules

- Grid lines sit below 10% opacity; they are a substrate, not a pattern.
- Match `cell` to the baseline and `module` to the column width.
- Content sits on the grid; break it deliberately once per page.
- Never place a grid behind another grid.

## Avoid

- Grids that do not align with the layout they support.
- Coloured grids used as decoration.
- Gradient fades over the grid to hide the edges.
