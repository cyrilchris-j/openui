# Editorial Navigation

Genre: Editorial
Macrostructure: Rail
Density: Compact
Shape: Sharp
Motion: Subtle
Typography: Serif Display
Color: Monochrome

## Motion

Fast: 140ms
Normal: 200ms
Slow: 320ms

## Rules

- Two tiers: a utility strip in monospace, an identity row in the display face.
- The active route is marked by a rule, not a filled pill.
- Keep primary navigation to seven items at most.
- The mobile disclosure is a labelled text control, never an icon alone.

## Avoid

- Sticky headers that consume more than 80px of viewport.
- Transparent headers that become opaque on scroll.
- Search fields inside the primary navigation row.
