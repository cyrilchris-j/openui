# Brand Press Kit Download

A media assets and brand press resource section with vector logos, color codes, and download bundles.

## Install

```bash
openui add brand-press-kit-download
```

Dependencies: none beyond React.

## What makes it distinct

- Category: `sections` → subcategory `brand`
- Interaction model: `brand-press-kit-download-interaction`
- Visual model: `brand-press-kit-download-visual`
- Motion model: `subtle`
- Semantic purpose: `brand-press-kit-download-section`

## Accessibility

- Keyboard reachable; visible focus ring.
- Honours `prefers-reduced-motion`: animation is disabled or replaced with a
  static state change.
- Semantic HTML first; ARIA only where the semantics need help.

## When to use

When the interface needs exactly this behaviour — check the fingerprint above
against the composition you are building.

## When not to use

When a simpler resource meets the need. Do not stack decorative motion on top
of a surface that already carries motion.
