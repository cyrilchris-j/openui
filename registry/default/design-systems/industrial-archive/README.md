# Industrial Archive

A dense, dark-first design system for data surfaces.

## Install

```bash
openui theme add industrial-archive
```

```ts
import "@/styles/industrial-archive.css";
```

## What it fixes

| Axis           | Position                                          |
| -------------- | ------------------------------------------------- |
| Genre          | Industrial                                        |
| Macrostructure | Mosaic                                            |
| Density        | Dense                                             |
| Shape          | Cut (10px corner, outer edge only)                |
| Motion         | Mechanical (140 / 240 / 420ms)                    |
| Typography     | Monospace primary, Inter for prose                |
| Colour         | Neon on dark, one amber signal                    |

## Fingerprint

Distinctiveness **84/100**. Strongest: cut geometry, monospace voice, mechanical
motion. The system is at its weakest when it is applied to prose — give long-form
text the `industrial-mono` overrides or use a different system.
