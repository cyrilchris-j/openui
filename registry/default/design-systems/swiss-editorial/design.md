# Swiss Editorial

Genre: Editorial
Macrostructure: Asymmetric
Density: Airy
Shape: Sharp
Motion: Subtle
Typography: Serif Display
Color: High Contrast

## Typography

Heading: Instrument Serif
Body: Inter
Mono: JetBrains Mono

## Motion

Fast: 180ms
Normal: 320ms
Slow: 600ms

## Rules

- Compose on a 7/5 split. A 50/50 layout is not a neutral choice, it is an absent one.
- Statements are set in the display serif above 24px; never below.
- Structure is drawn with hairlines, never with shadows or elevation.
- Metadata is monospace, uppercase, widely tracked, and small.
- Motion explains hierarchy or confirms input. It never decorates.
- One accent colour per page.

## Avoid

- Gradients used as background decoration.
- Rounded cards containing three identical feature columns.
- Centred display type over a symmetric stack.
- Elevation, drop shadows and glass blur.
- Two accent colours competing for attention.
