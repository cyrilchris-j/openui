# Status Pill

Genre: Technical
Macrostructure: Stack
Density: Dense
Shape: Sharp
Motion: None
Typography: Monospace
Color: Accent Only

## Rules

- Every tone pairs a colour with a glyph; state never depends on hue alone.
- Square corners, 11px monospace, uppercase, 0.16em tracking.
- The pill states a fact — it never carries an action.
- Provide an srLabel whenever the visible text is an abbreviation.

## Avoid

- Rounded badges with soft tints.
- Animated pulses for "live" states.
- Using the pill as a count badge; that is a different component.
