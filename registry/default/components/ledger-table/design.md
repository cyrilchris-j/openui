# Ledger Table

Genre: Industrial
Macrostructure: Stack
Density: Dense
Shape: Sharp
Motion: Subtle
Typography: Monospace
Color: High Contrast

## Motion

Fast: 120ms
Normal: 200ms
Slow: 320ms

## Rules

- Rules separate rows: no zebra striping, no card chrome, no shadows.
- Numbers are right-aligned with tabular figures so columns compare by shape.
- Headers are monospace uppercase at 11px with wide tracking.
- Sorting state is announced with aria-sort, not only with an icon.

## Avoid

- Row hover that changes the row height.
- Pagination controls inside the table surface.
- Truncating the identifier column.
