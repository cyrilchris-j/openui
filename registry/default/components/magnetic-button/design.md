# Magnetic Button

Genre: Editorial
Macrostructure: Asymmetric
Density: Medium
Shape: Sharp
Motion: Expressive
Typography: Grotesk
Color: Accent Only

## Typography

Heading: Instrument Serif
Body: Inter
Mono: JetBrains Mono

## Motion

Fast: 140ms
Normal: 220ms
Slow: 600ms

## Rules

- Motion answers the pointer; it never runs unprompted.
- Resting state must be indistinguishable from a plain bordered button.
- Clamp travel so the control never leaves its own footprint.
- Provide focus-visible styling that is visible on both paper and ink.

## Avoid

- Spring overshoot that pulls the label out from under the cursor.
- Decorating the magnet with colour, glow or blur.
- Animating on hover with no pointer movement.
