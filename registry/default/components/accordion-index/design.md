# Accordion Index

Genre: Editorial
Macrostructure: Rail
Density: Compact
Shape: Sharp
Motion: Subtle
Typography: Monospace
Color: Monochrome

## Motion

Fast: 140ms
Normal: 200ms
Slow: 400ms

## Rules

- The index number is the spine; keep it monospace and tabular.
- Structure comes from hairlines between items, never from card chrome.
- The open state is signalled by rotation of a rule glyph, not by colour alone.

## Avoid

- Chevron icons as the only affordance.
- Filled or rounded container panels per item.
- Animating height with JavaScript measurement.
