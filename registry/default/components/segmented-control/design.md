# Segmented Control

Genre: Swiss
Macrostructure: Rail
Density: Compact
Shape: Sharp
Motion: Subtle
Typography: Grotesk
Color: High Contrast

## Motion

Fast: 120ms
Normal: 180ms
Slow: 320ms

## Rules

- Segments share borders; the group is one object, not several buttons.
- The active segment inverts (ink on paper), it does not glow or pill.
- Labels are uppercase with 0.16em tracking at 11–12px.
- Selected state must be expressible without colour: inversion carries it.

## Avoid

- Floating pill segments with gaps between them.
- More than five options; use a select instead.
- Preselecting an option the user has not confirmed in a destructive flow.
