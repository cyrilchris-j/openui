# Class Name Merge

Genre: Technical
Macrostructure: Stack
Density: Compact
Shape: Sharp
Motion: None
Typography: Monospace
Color: Monochrome

## Rules

- A utility carries no styling of its own.
- Prefer explicit variant props over long conditional class lists.
- Never sort or deduplicate classes by hand; that is `cn`'s job.

## Avoid

- Hiding layout decisions inside a utility.
- Re-exporting a UI component from a utility module.
