# Prompt: Hero Composition

Copy this prompt and fill in the four slots. Keeping the slots explicit is the
point: most generic output comes from an underspecified brief, not from a bad
model.

---

Compose the opening section of a page.

**Product**: `{{what it is, one sentence, no adjectives}}`
**Reader**: `{{who arrives here and what they already know}}`
**Design system**: `{{design system name, or "none installed"}}`
**Resources available**: `{{paste the relevant entries from registry.json}}`

Constraints:

- Macrostructure is asymmetric. State the ratio you use and why.
- No centring. No three-column feature card grid. No decorative gradient
  (`anti-slop.md` rules 1, 2, 3).
- Type carries the hierarchy: display face for the statement, mono for metadata.
- Include one measurable piece of evidence (a count, a date, a constraint) rather
  than a benefit claim.
- Write the copy yourself. Do not use the words "seamless", "effortless",
  "supercharge", "unlock" or "beautiful".
- Everything present in the markup must be meaningful on a 390px viewport:
  recompose, do not hide.

Deliver, in this order:

1. the ratio and the band list (three to five bands)
2. the resource names you will use, taken from the list above
3. the copy, final
4. the component code
5. the audit score for the result, with the findings behind each number

Do not write any code before steps 1–3 are stated.
