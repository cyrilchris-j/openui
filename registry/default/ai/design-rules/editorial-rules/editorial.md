# Editorial Rules

## Composition

- Compose asymmetric: **7/5**, not 50/50. State the ratio you used.
- Enter at the top-right and exit down the left rail. The eye should travel, not bounce.
- One idea per band. Separate bands with hairlines, not backgrounds.
- Allow the widest element on the page to touch the viewport edge once.

## Typography

- Display serif above 24px for statements; never for body text.
- Body text set to a `68ch` measure, `1.6` line-height.
- Metadata: monospace, uppercase, `0.22em` tracking, 11px, graphite.
- Hierarchy from scale and case, not from colour or weight alone.
- Keep display line-height at or below `1.0`.

## Motion

- Three durations: `180 / 320 / 600ms`. Name them; do not invent a fourth.
- One easing curve across the page.
- Motion explains hierarchy, confirms input, or preserves context. Nothing else.

## Colour

- One accent. One neutral scale. One signal colour reserved for attention.
- Accents used on type must hold 4.5:1 against their background.

## Copy

- Say the specific thing. "Interfaces should have a fingerprint" beats
  "Build beautiful interfaces with AI".
- Prefer a concrete noun over an adjective. Prefer a claim over a benefit.
- Never use "seamlessly", "effortlessly", "supercharge" or "unlock".

## Self-check

Before returning a layout, report: the ratio you used, the type scale, the motion
durations, and which anti-slop rules you deliberately stayed clear of.
