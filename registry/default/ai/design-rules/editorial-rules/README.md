# Editorial Rules

A positive ruleset for editorial interfaces: composition, typography, motion,
colour and copy.

## Install

```bash
openui add editorial-rules
```

Written to `.openui/editorial.md`.

## Usage

Pair with `anti-slop` (what not to do) and a design system's `design.md` (the
project's own position). Order of precedence when they disagree:

1. the project's `design.md`
2. `anti-slop`
3. `editorial-rules`
